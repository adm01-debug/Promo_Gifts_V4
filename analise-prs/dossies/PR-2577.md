- `tests/scripts/preflight-migration-apply.test.mjs` — 2 novos casos: aceita identifier `$`-quoted no search_path; acusa `pg_temp` mencionado só no corpo

## Lógica da mudança

**Bug original:**
```javascript
const hasSetPath = /SET\s+search_path\s*(?:=|TO\b)/i.test(snippet);
const hasPgTemp = /pg_temp/i.test(snippet);  // qualquer ocorrência no corpo passava
```

**Fix:**
```javascript
const setPathMatch = /SET\s+search_path\s*(?:=|TO\b)([\s\S]*?)(?=\b(?:AS|LANGUAGE|SECURITY|...)\b|\$...\$|;|$)/i.exec(snippet);
const hasSetPath = setPathMatch !== null;
const hasPgTemp = hasSetPath && /pg_temp/i.test(setPathMatch[1]); // só no valor capturado
```

`pg_temp` só conta como proteção quando está explicitamente no valor do `SET search_path = ...`, não em comentários, strings ou outras partes do corpo da função.
