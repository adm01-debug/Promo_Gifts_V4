## Evidência

react-day-picker v8→v10 = dois saltos de major version. Mudanças breaking incluem:
- v9: remoção de `Modifiers` type, reestruturação de `DayPicker` props
- v10: nova API de `classNames`, mudança em `selected`/`onSelect` handlers

O PR (dependabot) atualiza apenas `package.json` e `package-lock.json`. Nenhum arquivo `src/` foi adaptado para a nova API.

Resultado: erros TypeScript em todos os componentes que usam `DayPicker`.

## Contexto

Atualização de segurança/features válida a longo prazo, mas requer refactor dos componentes consumidores antes de poder ser mergeada.
