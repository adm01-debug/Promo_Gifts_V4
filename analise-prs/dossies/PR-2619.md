## Resumo da mudança

Adiciona `Promise.race` com `CREDENTIAL_TIMEOUT_MS = 5000` ao método `getCredential()` dentro de `getExternalClient()` na edge function `health-check`. Sem timeout, chamadas de credencial podiam fazer o uptime-monitor aguardar indefinidamente (hang), causando falsos negativos de disponibilidade. Versão 1.3.0 → 1.3.1. O singleton reseta a si mesmo após timeout para permitir retry na próxima chamada.
