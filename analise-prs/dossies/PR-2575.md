## Lógica da mudança

`MagazineErrorBoundary` capturava `ChunkLoadError` e exibia UI de erro local, impedindo o handler global de detectar e tentar reload automático. Fix:

```typescript
import { isChunkLoadError } from '@/lib/chunk-recovery';
// ...
if (error && isChunkLoadError(error)) throw error;
```

Re-throw garante que erros de lazy-loading chunk (rede instável, deploy novo) cheguem ao handler global configurado em `tools-routes.tsx` via `MagazineRoute`.
